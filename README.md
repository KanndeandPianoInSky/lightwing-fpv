# Lightwing 光翼 · 5 寸 FPV 穿越机

这是一架采用定制机架的 5 寸穿越机。制作同款时，可以先看[英文配件表](docs/parts-list.txt)，再按用途选择图纸。

| 制作环节 | 文件 |
| --- | --- |
| 加工机架及附件 | [DWG 图纸](hardware/drawings)，含光翼二号减重版、1 mm 接收机挂架和起落架 |
| 查看机架设计 | [减重版 STEP 模型](hardware/models/lightwing-mk2-lightweight.stp) |
| 打印或修改镜头支架 | [STL 打印模型](hardware/models/camera-mount.stl) 和 [STEP 编辑模型](hardware/models/camera-mount.stp) |
| 查看升级件 | [GoPro 支架和飞行前拔除插头模型](hardware/upgrades) |
| 核对电子设备 | [接线参考图](docs/reference/wiring-reference.jpg)和[无图传版本登记图](docs/reference/registration-image-without-video-transmitter.png) |
| 查看实物与制作过程 | [项目照片](media/photos)和[制作与飞行截图](media/build-images) |

配件表列出的主要配置为银燕 RS2205 2300KV 电机、LANRC 60A 四合一电调、Aocoda-RC F405 V2 飞控和 DALPROP T5046C 桨。接线图仅供参考，请按实际硬件版本核对引脚。
