# Lightwing 5-Inch FPV Quadcopter

Lightwing uses a custom frame and a cylindrical plastic container as its fuselage. The container measures 65 mm in diameter and 100 mm in height. Start with the [bill of materials](docs/parts-list.txt) for the motors, electronics, propellers and radio equipment used in the build.

| Print or modify the camera mount | [Printable STL](hardware/models/camera-mount.stl) and [editable STEP model](hardware/models/camera-mount.stp) |
| Add optional hardware | [GoPro mount and remove-before-flight plug models](hardware/upgrades) |
